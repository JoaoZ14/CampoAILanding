## Como exportar

1. Abra `index.html` no Chrome.
2. Clique em **Modo exportar (1080×1350)**.
3. Capture cada slide (extensão de screenshot ou DevTools → Capture node screenshot no `.slide`).
4. Ou use **Imprimir / PDF** (uma página por slide).
